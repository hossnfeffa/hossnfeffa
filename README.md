## 🛡 Governance, Risk & Security Hardening

### [Generative AI Security Governance](https://github.com/hossnfeffa/Generative-AI-Security-Governance)

Cybersecurity capstone focused on governing generative AI use within a managed service provider environment. The project develops a security architecture combining **Microsoft Purview DLP, Defender for Endpoint, and Microsoft Sentinel** to reduce the risk of sensitive information being exposed through generative AI tools.

**Frameworks:** NIST CSF • NIST SP 800-53 • NIST AI RMF • CIS Controls v8

**Repository includes:** risk analysis, security architecture, implementation proposal, DLP and monitoring strategy, cost planning, technical report, and residual-risk analysis.

### [Windows 11 STIG Remediation](https://github.com/hossnfeffa/Windows-11-STIG-Remediation)

Hands-on Windows 11 security-hardening project implementing **DISA STIG controls with PowerShell**. Individual remediation scripts map security requirements to Windows configuration changes and include post-remediation validation.

**Focus areas:** DISA STIGs • PowerShell • Windows Hardening • Group Policy • Registry Configuration • Audit Policy • Compliance Validation

**Repository includes:** individual STIG remediation scripts, Vulnerability/CCI/SRG mappings, automated configuration changes, and `[PASS]` / `[FAIL]` verification logic.
